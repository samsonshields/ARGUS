# Phase 7 interface direction

ARGUS is a local evidence workstation. Keep the established dark theme and put source
provenance, review status and research context ahead of decorative dashboard treatments.

Palette: workspace navy #0d1520, evidence surface #152231, divider #304154,
primary text #e1e9f0, action cyan #80d2df, uncertainty amber #eac17b. Retain system
Segoe UI for fast local loading; 14-16px body text, 20px section headings and 30px page
headings. Monospace is reserved for hashes, offsets and dates. Body paragraphs target
readable widths; graph/map areas retain the available workspace width.

```text
Navigation | Research context / local status
           | Investigation breadcrumb and module links
           | Page title                      Primary action
           | Filters / review status
           | Results or evidence workspace
           | Selected record, provenance and review actions
```

All content is left aligned. Dashboard summaries group investigations, evidence review
and work queues instead of giving every count an equally prominent card. Editing forms
use available width for related short fields while reasoning and quotations stay wide.
Error, loading and empty states are distinct and give a concrete next action. Controls
wrap on narrow screens; keyboard focus, skip navigation and reduced-motion preferences
remain supported. No network fonts, decorative imagery or page-load animation is needed.

Review against the brief: retain the specified navy/cyan workstation identity, remove
phase labels from the product header, use borders for evidence/result grouping, and avoid
turning this data-intensive application into a marketing page or a repeated card grid.
